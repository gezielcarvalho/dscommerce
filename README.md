> **Repository status:** formative Spring Boot course exercise retained as a reference. It is not a completed commerce application or deployable service.

## What exists

The repository contains a Java 21/Spring Boot project, H2 development/test configuration, one initial `User` entity, Maven Wrapper files, and a context-load test.

No commerce API, repository, service, controller, catalog, order flow, or completed persistence mapping has been implemented.

## Decision

Retain only as a clearly labeled learning checkpoint, or archive it after owner review. A production or portfolio commerce project requires a separately scoped implementation.
